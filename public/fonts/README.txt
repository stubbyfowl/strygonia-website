Drop font files here.

Nordic (decorative accent face — used for the Strygonia wordmark and small
uppercase labels):
    Nordic.woff2   (preferred)
  optionally also  Nordic.woff / Nordic.otf / Nordic.ttf

MagiSans (body font, optional — falls back to Hanken Grotesk):
    MagiSans.woff2 / MagiSans.woff

Filenames are case-sensitive and must match exactly. After adding a file,
hard-refresh the browser (Cmd+Shift+R). No code changes needed — the
@font-face rules in src/styles/fonts.css pick them up automatically.
